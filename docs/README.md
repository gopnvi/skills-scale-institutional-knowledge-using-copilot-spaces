# OctoAcme Project Management Docs

This repository contains the core project management process documents used by OctoAcme. Together, these docs provide a lightweight, repeatable operating model for managing work from idea to delivery and continuous improvement.

## Summary of OctoAcme project management processes

OctoAcme follows a clear project lifecycle: initiation, planning, execution, release, and retrospective. During initiation, the team validates the business need, aligns stakeholders, and defines the project goal, success metrics, and early risks. Once approved, the team moves into planning, where work is prioritized, estimates are created, dependencies are identified, milestones are mapped, and a definition of done is documented. During execution, delivery teams manage work through a visible board, daily standups, weekly updates, and escalation paths when blockers appear.

The process emphasizes clear ownership across cross-functional roles. Product leads define outcomes and priorities, project managers coordinate schedules, risks, communication, and dependencies, developers build and validate solutions, and QA ensures the work meets acceptance criteria and quality standards. Communication is intentional and structured through regular standups, weekly syncs, stakeholder updates, and incident or status templates that keep everyone informed and aligned on decisions. Quality is built into the workflow through PR requirements, CI checks, automated tests, security scans, and smoke testing before release.

After delivery, the team follows a release and deployment playbook that includes staging validation, rollout coordination, smoke testing, and rollback readiness. The lifecycle closes with retrospectives and action tracking, allowing the team to capture lessons learned, improve the process, and make small iterative changes over time. This creates a sustainable project management rhythm that balances speed, accountability, and operational quality.

## How to use these docs

Use the overview and role docs for orientation, then move into the process docs for the stage of the project you are working on. The set is designed to help new team members quickly understand the lifecycle, responsibilities, communication cadence, and quality expectations that guide OctoAcme work.
